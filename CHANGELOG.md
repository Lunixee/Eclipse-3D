# Eclipse 3D changelog

## 0.1.0-alpha.1

- Eclipse 3D provides 3D scenes, GLB/glTF models, skeletal animation, physics, rendering and audio through TurboWarp blocks. It requires unsandboxed execution and WebGL 2.
- API v19 preserves existing Turbo3D projects, including the `turbo3d` extension ID and serialized block names.
- The palette includes Documentation, Example Project and Website buttons. Public URLs are configured before building a release.
- Documentation and eight editable example projects are included. First-Person Knife is playable without a viewmodel; owners of the separately purchased RGS_Dev asset can press I to load KnifeFPS.glb. The paid model is not included.

This is the current source version; no public release date is assigned yet.
